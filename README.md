# 卡厄思抽牌与暴击提示

读取当前战斗的本地状态，在独立副本中预测抽牌与暴击，不代替玩家操作游戏。

## 下载与使用

从 [Releases](https://github.com/slyzhydt/czn-battle-peek/releases/latest) 下载 `czn-battle-peek-0.1.0-preview.zip`。不要下载 GitHub 的 Source code ZIP 作为安装包：源码包不含 Python、Node.js 和读取依赖。

1. 完整解压到一个普通文件夹，正常进入战斗，等动画和开幕效果结束。
2. 双击 **启动提示.cmd**。如果提示权限不足，右键以管理员身份运行。
3. 读取期间停手，显示已断开后查看自动打开的本地网页。
4. 出牌后切回控制台按 **R** 刷新。按 **P** 输入连续动作；**T** 切换自动刷新；**Q** 退出。

**自动刷新.cmd** 会在每批完成后等待10秒再读。这是定时快照，出牌、选牌或结束回合后旧预测立即不再适用。

## 预测内容

- 当前普通抽牌顺序；不会把尚未发生的洗牌当成确定结果。
- 每张可用手牌打向各目标时的伤害与逐段暴击，包含追加效果。
- 连续指定出牌顺序中的入手牌、能量和手牌变化；选牌或灵光处停止。

各行默认都是“现在先打这张”的独立试算，不是依次打出的路线。连续路线如 `1:1 2:0 1:2`，牌位按每一步结算后的手牌解释；目标0代表无需指定，`E` 代表结束回合。一次最多20步。

## 兼容范围与证据

只识别 `collector/profile.json` 中已核对的 PC 客户端文件组合。原版本支持完整试算；另一个兼容版本目前仅支持状态与牌堆读取，不借用旧版规则预测暴击。缺失资源或未实现机制会阻止该动作，不猜测结果。

试用版已通过两份历史战斗的离线对照，以及一次新实机两步对照：抽两张牌后攻击，操作、手牌、牌库、随机数及完整战斗输入一致。此证据不代表所有角色和场景均已验证。打包版另作同状态完整重放检查，见 `VALIDATION.json`。

## 数据与日志

文件只留在本机，不自动上传。`runs` 保存读取及恢复回执；`latest.html` 是提示；`latest.json`、`plan.json` 是预测；`last-error.json` 和 `engine-error.log` 是错误信息。提交故障前请自行检查日志中的本机路径与战斗内容。

读取保留进程身份、精确版本、状态稳定和释放回执检查。若出现“恢复回执不完整”，保持控制台打开并正常退出游戏；不要强制卸载读取代码。

## 开发与构建

Python 3.11、Node.js 24.13.0、Frida 17.23.2、psutil 7.1.3。便携发行包附带运行环境，普通使用不需要单独安装。

运行离线检查：

```text
python -B -m unittest discover -s tests -v
node tests/verify-resources.mjs
```

`build_portable.py` 只按 `SOURCE-MANIFEST.json` 收集发布文件，拒绝源哈希变化，避免将运行记录夹带进发行包。传入已有已核对的 Python/Frida 运行时和 Node.exe 构建；第三方许可随包提供。
